What the sheet needs

  • A flat background the creature never uses — magenta is the convention. It is read from the corners, so it does not need to be exactly #FF00FF.
  • Clear gaps between frames and between rows. Frames that touch are found as one.
  • The same number of frames in every row.

Everything else is measured: where the rows sit, where each frame's edges are, and where the creature's body is so the frames line up instead of shuffling. If a row cannot be cut, it says which one and why.
